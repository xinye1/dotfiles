    Prerequisites

    This setup is a diff against EndeavourOS Sway Community Edition, not against bare upstream sway. Starting anywhere else means the "what stock does" reasoning in the playbook won't line up.

    You should be able to log in and get a bar, a terminal on $mod+Return, and a launcher on $mod+d before changing anything.

    shell
    ❯ pgrep -x sway && echo "sway running"
❯ pgrep -xc swayidle          # stock leaks these — see phase 05
❯ ls /usr/share/themes
    01

    Packages

    Five additions over the CE base. The Nerd Font is the one people skip — everything appears to work without it because fontconfig silently falls back.

    shell
    ❯ sudo pacman -S --needed ttf-jetbrains-mono-nerd kanshi papirus-icon-theme

    ttf-jetbrains-mono-nerd — the patched font. kanshi — display hotplug profiles. papirus-icon-theme — icons for mako, fuzzel and GTK.

    shell
    ❯ yay -S nordic-theme papirus-folders

    Nothing in the base install provides a Nord GTK theme. papirus-folders supplies the recolouring script used in phase 05.

    Check

    fc-match "JetBrainsMono Nerd Font"not NotoSansMono
    ls /usr/share/themes/Nordicexists
    02

    Clone the repo

    Location matters. .stowrc pins --target=~ precisely because the repo does not live in $HOME — stow would otherwise link into the repo's parent.

    shell
    ❯ mkdir -p ~/repos && cd ~/repos
❯ git clone https://github.com/xinye1/dotfiles.git
❯ cd dotfiles
    shell
    ❯ sudo pacman -S --needed stow
    03

    Clear the conflicts

    Stow will not replace a real file with a symlink. A fresh install already has all of these, so they must move aside first — this is the step that fails if you skip it.

    shell
    # ~/.bashrc comes from /etc/skel on every Arch install
❯ mv ~/.bashrc ~/.bashrc.bak

# Folded packages need the whole directory gone, not just its files
❯ for d in sway waybar mako fuzzel nwg-drawer gtklock foot; do
❯     mv ~/.config/$d ~/.config/$d.bak 2>/dev/null
❯ done

# gtk is tracked file-by-file, so move only the tracked files
❯ mv ~/.gtkrc-2.0 ~/.gtkrc-2.0.bak 2>/dev/null
❯ rm -f ~/.config/gtk-3.0/settings.ini ~/.config/gtk-4.0/settings.ini
❯ rm -f ~/.config/gtk-4.0/gtk.css ~/.config/gtk-4.0/gtk-dark.css

    The two gtk-4.0 symlinks point into /usr/share/themes/Arc-Dark. They must go, or stow can't place the libadwaita overrides.

    Two large images live inside stock config dirs — a 3.3 MB wallpaper in ~/.config/sway and a 22 MB lock screen background in ~/.config/gtklock. Neither belongs in a dotfiles repo. Move them to ~/Pictures/wallpapers if you want to keep them; this setup uses a solid Nord background instead.

    04

    Stow the packages

    Always dry-run first. Stow exits 0 even when it links to the wrong place, so the exit code proves nothing — the dry run's output is the real check.

    shell
    ❯ cd ~/repos/dotfiles
❯ stow -n -v bash vim starship alacritty foot waybar \
        sway kanshi gtk mako fuzzel nwg-drawer gtklock

    Every LINK: line must point at ../repos/dotfiles/…. Any CONFLICT means phase 03 was incomplete.

    shell
    ❯ stow bash vim starship alacritty foot waybar \
        sway kanshi gtk mako fuzzel nwg-drawer gtklock

    Check — every path must resolve inside the repo

    readlink -f ~/.config/sway~/repos/dotfiles/…
    readlink -f ~/.config/waybar~/repos/dotfiles/…
    readlink -f ~/.gtkrc-2.0~/repos/dotfiles/…
    ls -la ~/.config | grep gtk-3.0real dir, not a link

    Folded vs unfolded. gtk and alacritty are deliberately not folded — nwg-look writes into the GTK dirs, and alacritty's themes/ clone lives inside its own. For those two, a newly added file is silently absent until you run stow -R <pkg>.

    05

    Steps that can't be stowed

    Untracked clones and things that write outside $HOME.

    shell
    ❯ sudo papirus-folders -C nordic -t Papirus-Dark

    Yes, nordic — not nord. papirus-folders rejects nord outright. Despite the name the icons are genuine Nord: folder-nordic.svg is drawn in #5E81AC, #81A1C1 and #ECEFF4. The GTK theme is likewise named Nordic. Run papirus-folders -l to see the list.

    shell
    # alacritty.toml imports themes/themes/nord.toml from this clone
❯ git clone https://github.com/alacritty/alacritty-theme \
        ~/.config/alacritty/themes

# vim status bar
❯ git clone https://github.com/itchyny/lightline.vim \
        ~/.vim/pack/plugins/start/lightline

    XDG_CURRENT_DESKTOP is empty in a stock session, and xdg-desktop-portal picks its backend from it. The sway config repairs this for systemd and dbus — which is what portals actually read — but only greetd can put it in sway's own environment. In /etc/greetd/config.toml:

    /etc/greetd/config.toml
    command = "env XDG_CURRENT_DESKTOP=sway sway"
    06

    Apply and verify

    Validate before reloading — a bad config on reload leaves you with a half-applied session.

    shell
    ❯ sway --validate -c ~/.config/sway/config
❯ swaymsg reload

    Log out and back in once afterwards, so the exec-only startup commands run.

    shell
    ❯ pgrep -xc swayidle
❯ fc-match "JetBrainsMono Nerd Font"
❯ swaymsg -t get_outputs | grep -E '"name"|"scale"'
❯ gsettings get org.gnome.desktop.interface color-scheme
❯ systemctl --user show-environment | grep XDG_CURRENT

    Expected

    pgrep -xc swayidle1
    fc-match …JetBrainsMonoNerdFont
    scale2.0
    color-scheme'prefer-dark'
    XDG_CURRENT_DESKTOPsway

    $mod+d launcher · notify-send test · $mod+Shift+d drawer · the waybar clock tooltip · $mod+f1 lock · thunar for GTK3 · any libadwaita app · $mod+Return terminal.

    A libadwaita app rendering light is the tell that ~/.config/gtk-4.0/gtk.css didn't land.

    07

    Traps worth knowing

    Each of these produced a real bug in this setup. Full detail in PLAYBOOK.md §9.

    TrapWhat happensGuard
    nwg-look Rewrites every tracked GTK file on Apply; may replace stow symlinks outright git status after using it, then stow -R gtk
    exec_always Spawns another daemon on every reload — this is what leaked 40 swayidle processes Prefix with pkill -x <name>;
    exec Runs only at startup, so a reload can't repair it — the fix looks broken Use exec_always for anything idempotent
    exec export Silently does nothing; the subshell exits with the variable systemctl --user set-environment
    Font names fc-match returns something for any string, so a wrong name looks fine Family name has a space; Nerd Font is a distinct family
    stow exit code 0 even when it linked somewhere wrong readlink -f, never $?
    azote Rewrites ~/.azotebg and starts a swaybg over sway's background pkill swaybg and reload
    config.d order Read alphabetically; theme sorts last and wins Name overrides zz-local
